LiteBrawl 测试服务器 Paper 1.21.1

随机出生点大乱斗 · 已装好插件，三步就能进游戏

这个压缩包里是一个可以直接跑起来的服务端，插件已经放进 plugins/ 了。 你要做的只有下面三件事。需要 Java 21（下载）。

1

同意 Minecraft EULA

用记事本打开 eula.txt，把 eula=false 改成 eula=true。 这一步必须由你自己完成（EULA 原文）。

2

启动服务器

Windows 双击 start.bat；Linux / macOS 运行 ./start.sh。 首次启动要生成世界，大约 30~60 秒，看到 Done (...) 就是好了。

3

进游戏

在 Minecraft 里添加服务器 127.0.0.1:25565。 本包是离线模式（online-mode=false），不需要正版账号，方便本地测试。

强烈建议先看网页控制台。启动后控制台会打印一行 http://127.0.0.1:8787/?token=...，复制到浏览器打开—— 里面有开服向导、可视化配置、YAML 编辑器和实时状态，比手改配置文件快得多。

进服前：先建一张地图

插件不会凭空生成地形，要把服务器目录里真实存在的世界注册进来。 在控制台依次执行（/map setspawn 需要游戏内管理员站在出生点上执行）： 

/maps create world 测试地图
/map setspawn
/map scan

/map scan 只读取地图里已有的绿宝石方块，不会放置任何方块。 扫描后用 /lb status 确认「出生方块」数量大于 0 即可开局。

常用命令

命令作用
/start进入战场（也可以右键大厅 8 号槽的下界之星）
/shop商店（只能在大厅用）
/stats /top /board战绩、聊天版排行、排行榜面板
/team组队（队伍内互相免伤）
/link拿到网页玩家面板绑定码
/lb status一次性看清服务端状态
/lb bot spawn 4手动放几个陪练假人

常见问题

双击 start.bat 一闪而过

Java 没装好，或不是 21。打开命令行执行 java -version 检查。

提示端口被占用

已经有别的服务端在跑。改 server.properties 里的 server-port。

假人不出现

假人是僵尸，世界难度必须是 easy 或更高。本包已设为 easy； 如果你改成 peaceful，僵尸会被立刻清除。

换了新版本插件 jar，但行为没变

Paper 会缓存 remap 后的插件。停服后删掉 plugins/.paper-remapped/ 再启动。

网页控制台打不开

默认只监听 127.0.0.1，只能本机访问；地址里的 token 要和控制台打印的一致。
